# گالری شخصی (Kheili)

اپ اندرویدی فارسی و راست‌به‌چپ برای نگهداری خصوصی عکس و ویدئو با ورود PIN یا اثر انگشت. نام و آیکن برنامه عمداً خنثی و شبیه یک گالری معمولی است؛ داخل برنامه، هدف و وضعیت امنیتی به‌صورت شفاف نمایش داده می‌شود.

## قابلیت‌های نسخه اول

- ورود با BiometricPrompt (اثر انگشت/قفل دستگاه) و کد حداقل چهاررقمی
- رابط RTL فارسی با بخش‌های همه موارد، عکس‌ها، ویدئوها و پوشه‌ها
- جست‌وجوی متنی در رابط کاربری و انتخاب عکس/ویدئو از فایل‌های دستگاه
- حداقل Android 8 و target Android 15؛ مناسب برای Xiaomi Note 14
- بدون اینترنت و بدون سرور خارجی
- رمزنگاری AES-GCM برای فایل‌های واردشده با کلید ۲۵۶بیتی در فضای خصوصی اپ

## ساخت APK

Android Studio Ladybug یا جدیدتر را نصب کنید، پروژه را باز کنید و از Build > Build APK(s) استفاده کنید. برای انتشار نهایی، PIN باید با Android Keystore و فهرست‌سازی دائمی/پوشه‌بندی کامل ممیزی شوند. چون Android SDK در محیط فعلی موجود نیست، APK و تست روی دستگاه فیزیکی در این اجرا قابل تأیید نیست.
